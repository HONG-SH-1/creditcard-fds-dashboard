# F1 vs F2 (보고서용 메모)

보고서에 넣을 **숫자**는 `report_outputs/`를 돌린 뒤 나온 실측 값으로 채우면 된다. 아래는 **용어를 어떻게 풀어 쓸지**에 대한 메모다.

## 정의를 한 줄씩

- **F1**  
  Precision(“사기라고 한 것 중 진짜 사기 비율”)과 Recall(“진짜 사기 중 잡아낸 비율”)을 **같은 비중**으로 섞은 점수다. FP와 FN을 대칭적으로 볼 때 요약 지표로 쓰기 좋다.

- **F2**  
  같은 식인데 Recall 쪽에 더 큰 가중을 둔다(β=2). “사기를 놓치는 것”이 더 큰 비용일 때 이쪽을 본다.

- **PR-AUC**  
  임계값을 하나로 고정하지 않고, 임계값을 바꿔 가며 나오는 Precision–Recall 관계를 한 숫자로 요약한 것에 가깝다. **순위가 얼마나 나은지**를 볼 때 쓰고, 불균형 데이터에서는 ROC-AUC만 볼 때보다 덜 낙관적인 경우가 많다.

## 이 프로젝트에서의 역할

- 대시보드에는 Recall과 F2를 같이 보여 주고, PR-AUC는 “모델이 확률 순위를 얼마나 잘 매기는지” 참고용으로 고정 표시한다(임계값과 무관).  
- `scripts/model_comparison.py`에서 하이퍼파라미터를 맞출 때 교차검증 점수로 **F2**를 쓴다.  
- F1은 같은 테스트 세트에서 **비교·설명용**으로 같이 적어 두었다.
